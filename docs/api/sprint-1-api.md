# Sprint 1 API guide

The canonical machine-readable contract is generated by FastAPI at `/openapi.json`; interactive
documentation is available at `/docs` outside production. All product routes are versioned under
`/api/v1`.

## Error contract

Every expected HTTP failure uses the same safe envelope. `code` is stable for software,
`message_key` is safe for localization, `request_id` correlates telemetry, and `details` identifies
invalid fields without exposing internals.

```json
{
  "error": {
    "code": "unsupported_file_type",
    "message_key": "errors.unsupported_file_type",
    "request_id": "d337b131-70be-4f84-9b07-f5cbdbdeec88",
    "details": [{"field": "file", "code": "mime_mismatch"}]
  }
}
```

## User journey

### Create a collection

```http
POST /api/v1/collections
Content-Type: application/json

{"name":"Company handbook","description":"Policies for support staff"}
```

Returns `201` with the collection UUID. Sprint 1 uses a configured development user; a verified
authentication adapter replaces this boundary before public release.

### Upload a document

```http
POST /api/v1/collections/{collection_id}/documents
Content-Type: multipart/form-data

file=@handbook.pdf
```

The API streams inspection, calculates SHA-256, stores the original, persists an immutable version
and job, and returns `202` promptly:

```json
{
  "document_id": "…",
  "document_version_id": "…",
  "job_id": "…",
  "collection_id": "…",
  "display_name": "handbook.pdf",
  "version_number": 1,
  "status": "queued",
  "job_status": "pending",
  "stage": "queued",
  "created_at": "2026-09-24T08:00:00Z"
}
```

### List and inspect processing

`GET /collections/{collection_id}/documents?page_size=20` uses a deterministic opaque cursor.
`GET /collections/{collection_id}/documents/{document_id}` exposes safe stages and failure codes.
`POST /collections/{collection_id}/documents/{document_id}/ingestion-retries` safely retries only a
failed version.

### Create a conversation and stream an answer

```http
POST /api/v1/collections/{collection_id}/conversations
Content-Type: application/json

{"title":"Policy questions"}
```

```http
POST /api/v1/conversations/{conversation_id}/messages:stream
Accept: text/event-stream
Content-Type: application/json

{"question":"مرخصی سالانه چند روز است؟","language":"auto"}
```

SSE events are ordered as follows:

```text
retrieval_started  {rag_run_id, request_id}
retrieval_completed {evidence_count, request_id}
answer_delta       {text, request_id}       # zero or more
citations          {items: [...], request_id} # only backend-validated evidence
completed          {rag_run_id, answer_message_id, abstained, timing, request_id}
failure            {code, message_key, request_id} # terminal alternative
```

Disconnect cancels the generator and persists a cancelled RAG run. A client may retry the question;
each attempt intentionally creates a separate reproducible run.

## System endpoints

- `GET /health`: process liveness only.
- `GET /ready`: PostgreSQL, Redis, and object-storage readiness.

No endpoint returns storage keys, prompts, provider exceptions, credentials, embeddings, or stack
traces.
